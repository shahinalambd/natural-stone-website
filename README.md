# Natural Stone Co. Website

An elegant website concept for a marble, granite and natural stone supplier serving Oman and the UAE.

## Live preview

https://shahinalambd.github.io/natural-stone-website/

## Key features

- 5 pages: home, products, projects, about and contact
- Hero slideshow with progress bars and animated counters
- Filterable product catalogue with detail modals
- Project gallery with filters and lightbox
- Office location tabs with embedded Google Maps
- Quote request form with client-side validation
- Scroll reveals and a fully responsive layout

## Tech used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts
- No build step, so the site runs as plain static files

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- All contact details are placeholders (`+000 0000 0000`, `hello@example.com`).
- Forms are static demos: they validate input but do not send any data.
